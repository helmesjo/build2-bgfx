# libbx-tests - Unit tests for libbx

This is a `build2` package containing the test suite for the
[bx](https://github.com/bkaradzic/bx) library (upstream unit tests).


## Importable targets

This package exports no targets.


## Configuration variables

This package provides no configuration variables. Assert-heavy checks follow
`config.libbx.debug` from the `libbx` dependency.
